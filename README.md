## Acerca del Proyecto

**FORMULARIO WEBPACK** es un proyecto desarrollado como parte del plan de estudios de SysAdmin Network del SENA. Consiste en un formulario web que utiliza Webpack para la gestión de módulos y la automatización de tareas de desarrollo.

## Construido con

### Tecnologías

- HTML
- CSS
- JavaScript
- Webpack
- Git
- GitHub

### Características Clave

- Configuración de Webpack para la gestión eficiente de módulos.
- Uso de linters para mantener la calidad del código.
- Formulario web responsivo y accesible.

## Comenzando

### Requisitos Previos

Para ejecutar este proyecto, necesitas tener instalados los siguientes programas:

- [Node.js](https://nodejs.org/)
- [npm](https://www.npmjs.com/)
- [Git](https://git-scm.com/)

### Instalación

Sigue estos pasos para configurar el proyecto en tu máquina local:

1. Clona el repositorio:

   ```bash
   git clone https://github.com/Dajs4/formulario-Linters.git
   ```

2. Navega al directorio del proyecto:

   ```bash
   cd formulario-Linters
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

### Uso

Para ejecutar el proyecto en un entorno de desarrollo:

```bash
npm start
```

Esto iniciará un servidor de desarrollo y abrirá el proyecto en tu navegador predeterminado.

### Ejecutar Pruebas

Para ejecutar las pruebas, utiliza el siguiente comando:

```bash
npm test
```

### Despliegue

Para crear una versión lista para producción del proyecto:

```bash
npm run build
```

Los archivos de producción se generarán en el directorio `dist`.
